# Сервис онлайн обучения
## 📌 Описание проекта
Сервис позволяет пользователям создавать централизованную платформу для управления учебными материалами, заданиями, оценками и взаимодействием между участниками обучения. 


## 🚀 Функциональность
## Основная часть (обязательная по ТЗ):
#### ✅ CRUD для клиентов (email, номер телефона, город, аватар)
#### ✅ CRUD для курсов (название, превью, описание, цена)
#### ✅ CRUD для уроков (название, превью, описание, курс, ссылка, цена)
#### ✅ CRUD для платежа (время начала/окончания, вид оплаты, ссылка на оплату, id сессии)
#### ✅ CRUD для подписки (пользователь, курс)
### Дополнительная часть (расширение функциональности):
#### ✅ Регистрация и аутентификация пользователей (через email)
#### ✅ Вход/выход, подтверждение email через письмо
#### ✅ Ограничение доступа: пользователь видит только свои данные, модератор — все
#### ✅ Роли:модераторы, неавторизованные пользователи и владельцы курсов
#### ✅ CRUD операции описаны через ViewSet и Generic классы
#### ✅ Описаны сериализаторы для каждой модели
#### ✅ Описана пагинация 
#### ✅ Создан валидатор для проверки подписки
#### ✅ Описан пермишн для владельцев, модераторов и обычных пользователей
#### ✅ Написаны тесты через unittest

## 📂 Установка
Клонировать репозиторий:
```
 git clone https://github.com/yourname/django_rest.git`
cd django_rest
```

Создать и активировать виртуальное окружение:
```
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```
Установить зависимости:
```
pip install -r requirements.txt
```
